Run Lumen On This Mac

Use this when the repo already exists on your computer. It starts the Python agent, local web console, and bottom-right desktop orb.

cd ~/Documents/Code/Lumen && uv run python -m lumen.main

After it starts, this page should detect the local console and enable the Open Console button.

02

Local Models

Lumen expects local models through Ollama or LM Studio. Model weights are never shipped from this website or stored in the repo.

ollama pull qwen3:latest
03

Voice Mode

Voice support is optional. Install the voice extras only on machines that need local speech transcription.

uv sync --extra voice

Fresh install

Install Lumen From GitHub

For a new user machine, install prerequisites, clone the repo, then start Lumen locally. The public site can guide the install, but the user must approve commands in Terminal.

/bin/bash -c "$(curl -fsSL https://lumen.ompatnaik.com/install.sh)"
git clone https://github.com/OmTheLast/Lumen.git ~/Documents/Code/Lumen
