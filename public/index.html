Local-first macOS agent

Lumen

A desktop agent framework that listens, plans, and acts on your computer while keeping the real execution loop local.

GitHub Architecture
01

Local Runtime

The Python agent runs on macOS, talks to local models, and owns desktop tools like apps, browser actions, screenshots, files, and shell commands.

02

Model Choice

Lumen can detect Ollama and LM Studio models, then save planner, router, and voice transcription choices in a local config file.

03

Web Surface

This Cloudflare Worker hosts the public project page. The private control surface stays bound to the local agent process.
